# Clubhouse mod by Darhous

**سطح تحكم مباشر لمشرفي غرف Clubhouse — يشتغل عندك بالكامل، من غير سيرفر خارجي ولا وسيط.**

[🇬🇧 English](README.md) · [🇪🇬 العربية](README.ar.md)

</div>

عملت البرنامج ده لسبب واحد بسيط: إدارة غرفة Clubhouse حية من التطبيق نفسه بس تعب حقيقي — الطابور بيتحرك أسرع من إيدك، مش قادر تشوف مين مين بنظرة واحدة، ومفيش تراجع لو غلطت. ده البرنامج اللي كنت محتاجه أنا نفسي. كل شاشة، كل حماية، كل تأخير عمدي عشان محدش يضرب حماية سبام في Clubhouse — كله جاي من تجربة حقيقية وأنا بديره على غرف فعلية، مش من ورقة مواصفات. لو انت كمان بتدير غرف، أتمنى يوفرلك نفس الصداع اللي وفره ليا.

## التشغيل السريع

**اللي محتاجه**: [Node.js](https://nodejs.org) نسخة 18 أو أحدث. مفيش حاجة تانية — لا قاعدة بيانات، لا خدمات خارجية، لا خطوة بناء.

```bash
git clone https://github.com/Darhous/clunhouse-mod.git
cd clunhouse-mod
npm install
npm start
```

بعدين افتح **http://localhost:4545** — كده خلصت التثبيت بالكامل.

> على ويندوز، تقدر كمان دبل كليك على **`تشغيل.bat`** — بتشغّل السيرفر وتفتحلك المتصفح لوحدها.

البرنامج بيشتغل عادي من غير أي إعداد إضافي بأي طريقة من التلاتة دول:

| الطريقة | محتاج إيه | فين بتتظبط |
|---|---|---|
| **مساعد لـ Clubdeck** (صفر إعداد) | [Clubdeck](https://www.clubdeck.app/) مثبت ومسجّل دخول على نفس الجهاز | تلقائي بالكامل — شوف [بيانات الجلسة منين](#بيانات-الجلسة-منين) |
| **توكين + آيدي المستخدم** | توكين حسابك على Clubhouse ورقم الآيدي بتاعك | تاب *إدارة الحسابات* ← *تسجيل دخول بتوكين* |
| **رقم الهاتف** | رقم هاتفك المسجّل على Clubhouse | تاب *إدارة الحسابات* ← *تسجيل دخول برقم الهاتف* (OTP)، من غير أي احتياج لـ Clubdeck |

## بيانات الجلسة منين

افتراضيًا، السيرفر بيدوّر على **ملف جلسة Clubdeck نفسه** ويقرا منه أي حساب Clubhouse مسجّل دخول فيه دلوقتي — بنفس الطريقة اللي جهاز Clubdeck شايفك بيها. المسار بيتحدد أوتوماتيك:

```
%LOCALAPPDATA%\Programs\Clubdeck\profile.json
```

`%LOCALAPPDATA%` دايمًا بيشاور على فولدر المستخدم بتاعك انت على ويندوز، فده بيشتغل من غير أي تعديل لأي حد يعمل clone للريبو — مفيش مسار شخصي لحد معيّن متكتوب هنا. مفيش حاجة بتتنسخ أو تتخزن أو تتبعت لأي مكان: البرنامج بيقراه لحظيًا من على جهازك انت بس.

لو عايز تشتغل من غير أي اعتماد على Clubdeck خالص، استخدم تسجيل الدخول بالتوكين أو بالهاتف فوق — الاتنين مش محتاجين Clubdeck مثبت أصلًا. أي طريقة تستخدمها، بيانات حسابك متسيبش جهازك أبدًا: مفيش سيرفر خارجي، مفيش تحليلات، مفيش تتبّع. السيرفر هو جهازك انت.

## المميزات

| الميزة | بتعمل إيه | الإندبوينت/الفكرة |
|---|---|---|
| لوحة الغرفة الحية | قائمة الحضور والأدوار وحالة الغرفة لحظيًا، بتحدّث نفسها تلقائي | polling على `get_channel` + Server-Sent Events |
| طابور طلبات التحدث | شوف مين رافع إيده، ادعِ واحد/أول N/الكل، رتّب الطابور، واحتفظ بنسخة احتياطية لو الطابور فرغ فجأة | `get_handraise_queue`, `invite_speaker` |
| التحكم في المسرح والجمهور | كتم/دعوة/إنزال/طرد، فردي أو جماعي، بحد سرعة إرسال مشترك بين كل الأكشنات الجماعية | `mute_speaker`, `invite_speaker`, `uninvite_speaker`, `block_from_channel` |
| شات الروم | اقرا وابعت في شات الغرفة النصي، لايك/إلغاء لايك، حذف (مودريتور)، ترحيب تلقائي حسب دور الداخل | `get_channel_messages`, `send_channel_message`, `like_channel_message` |
| رياكتس وتأثيرات | رياكت فردي أو كومبو أو جماعي، GIFs، كل ده بفاصل زمني عشان محدش يضرب حد سبام Clubhouse | `emoji_reaction`, `gif_reaction` |
| الأتمتة والحماية | دعوة تلقائية للـVIP، موديريشن تلقائي للقائمة السوداء مع انتهاء صلاحية، تبريد احتكار المايك، حد أقصى لوقت التحدث، ساعات هدوء، دوران أدوار | محرك قواعد محلي فوق حلقة المراقبة |
| تعدد الحسابات | بدّل بين جلسة Clubdeck وأي عدد من الحسابات المسجّلة يدويًا | `lib/account.js` |
| الغرف المباشرة والهاوسات | تصفّح الفيد العام، ادخل أو راقب بدون مشاركة، أدر هاوساتك وأعضائها | `get_feed_v3`, `get_social_club_members` |
| الرسائل الخاصة | اقرا المحادثات، اقبل/اخفِ الطلبات، قبول جماعي لكل الطلبات المعلّقة | `get_chats`, `accept_dm_conversation_request` |
| الشبكة الاجتماعية | بحث، متابعة/إلغاء متابعة/حظر، متابعون مشتركون، مين أونلاين من متابعينك | `search_users`, `get_followers` |
| الأصدقاء والإشعارات | مراقب خلفي بينبهك لما صديق بتتابعه يدخل غرفة | `lib/friendsWatcher.js` |
| عمليات جماعية آمنة | معاينة ← تجربة بدون تنفيذ ← تنفيذ فعلي، بتقدّم حي وإلغاء بضغطة واحدة — مفيش حاجة بتتنفذ عمياني | `lib/operationManager.js` |
| أرشيف الجلسات وسجل الأكشنات | كل غرفة سابقة محفوظة محليًا، وكل أكشن عملته مسجّل وقابل للبحث | `lib/state.js` |
| سجل الـAPI الحي | كل طلب ورد من/لـ Clubhouse، بتوقيت زمني، وقابل للتصدير — لو محتاج تعرف بالظبط إيه اللي حصل | `lib/logBuffer.js` |
| تشخيص ذاتي | شاشة واحدة توضح حالة السيرفر والحساب والغرفة وعقود الـAPI — من غير أي نداء خارجي | `/api/platform/diagnostics` |

الجدول ده أهم النقط بس. المرجع الكامل route بـroute موجود في [`docs/`](docs/) — تحت كده.

> البحث عن GIF اختياري: محتاج [مفتاح Giphy API مجاني](https://developers.giphy.com/) تحطه في تاب *الإعدادات*. كل حاجة تانية شغالة من غير أي إعداد إضافي.

## التوثيق

فيه ملفين مرجعيين جوه [`docs/`](docs/)، اتكتبوا مباشرة من الكود الفعلي مش من الذاكرة — كل شكل request/response فيهم اتأكد من اللي الكود فعلًا بيبعته ويستقبله:

- **[`CLUBHOUSE_API_ENDPOINTS.md`](docs/CLUBHOUSE_API_ENDPOINTS.md)** — كل إندبوينت من Clubhouse البرنامج بيكلمه: العنوان الأساسي، هيدرز الهوية، بصمة "العميل الحديث" اللي بعض أكشنات الغرفة محتاجاها، آلية الحماية من الحظر، وجدول كامل لكل إندبوينت بحالة تحققه (مؤكد حيًا / تخمين معقول / معروف إنه اتلغى).
- **[`INTERNAL_SERVER_API.md`](docs/INTERNAL_SERVER_API.md)** — كل مسار محلي البرنامج بيعرضه على `localhost:4545`، إزاي قناة التحديث اللحظي شغالة، وشرح تفصيلي لنظام شات الروم تحديدًا (context tokens، سرعة الـpolling، منع التكرار) — لو حابب تبني حاجة فوقه، بوت تيليجرام مثلًا أو أي حاجة تانية.

الملفين بالعربي، متوافقين مع لغة واجهة البرنامج نفسها — بس أسماء الإندبوينتس والمسارات والكود زي ما هي بالظبط في المصدر.

## إزاي اتبنى

Node.js عادي (موديول `http`، من غير أي framework) بيكلم مباشرة الـAPI الخاص بـ Clubhouse — نفسه اللي Clubdeck نفسه بيستخدمه، اتفهم بالرصد والملاحظة مش من توثيق رسمي، لأن Clubhouse مفهوش توثيق منشور أصلًا. حلقة مراقبة كل 3 ثواني (`lib/poller.js`) بتراقب الغرفة وتبعت التحديثات للمتصفح عبر Server-Sent Events — مفيش WebSocket، مفيش اعتمادية خارجية، مفيش حاجة تظبطها.

## الأمان في التصميم

Clubhouse بيوقف الرياكتس والرسائل مؤقتًا لو اتبعتت بسرعة كبيرة — عرفت ده بالتجربة الصعبة. كل أكشن جماعي بيشارك حد سرعة إرسال دائم لكل حساب (`lib/featureLimiter.js`) بيوقف نفسه تلقائيًا لو حصل رفض حقيقي بدل ما يكمل يضرب، وأي أكشن لا رجعة فيه (طرد، إنهاء الغرفة، حذف رسالة) بيعدي على تأكيد صريح يوضح بالظبط اللي هيحصل.

## حدود معروفة

فيه كذا إندبوينت من Clubhouse موثّق إنه معطل أو غير مؤكد أو ممنوع عمدًا — شوف عمود "الحالة" في [`CLUBHOUSE_API_ENDPOINTS.md`](docs/CLUBHOUSE_API_ENDPOINTS.md) للقايمة الكاملة الصريحة بدل الدعاية. باختصار: تسجيل دخول بالبريد والباسورد مش ممكن (Clubhouse مفيهوش API بيدعم ده)، وفيه إندبوينتس قديمة Clubhouse نفسه ألغاها لسه متسجلة في السجل بس كأثر لما كان شغال قبل كده.
